# 哈基米音效包

这些不是合成音，而是从用户提供的**第二段视频**音轨中截取的完整短语采样：

- `phrase-*.mp3`：5 段完整乐句 / 人声片段，约 1.5–2.4 秒
- 不再使用第一段视频里的猫哈气噪声，也不再切成 0.1–0.3 秒的碎片

截取时参考了源音轨的波形、能量谷和 VAD 语音区间，每段都做了：

- 单声道 44.1 kHz、MP3 96 kbps
- 响度归一化和峰值限制
- 约 30 ms 的淡入淡出，避免硬切爆音
- 共享一个随机池：5 段全部打乱后依次播放，播完一轮才重新洗牌，避免连续重复
- 点击时如果上一句还没说完，会让它继续说完；落牌时可以打断上一句并播放新一句

源视频由项目使用者提供，仅作为本项目音效采样使用。
